## 📱 Proyecto Destacado (Mobile): Sistema de Gestión de Almacén

Solución móvil integral diseñada para pequeños comercios, optimizada para funcionamiento **offline** y gestión eficiente de recursos.

* **Repositorio:** [Almacen](https://github.com/davidcardozodeveloper/Almacen)
* **Tecnologías:** React Native, Expo, TypeScript, Styled Components y AsyncStorage.
* **Gestión de Ventas:** Módulo dinámico con carrito de compras y gestión visual de stock en tiempo real.
* **Análisis Visual:** Generación de estadísticas mediante gráficos de torta y barras para el seguimiento de ingresos.
* **Herramientas Pro:** Exportación de reportes a **PDF/Excel (CSV)** y sistema de **Backup & Restore** en formato ZIP.
* **Accesibilidad:** Soporte para modo oscuro e interfaz multi-idioma (i18n).

## 🚀 Proyecto Destacado (Web/Terminal): Safe Stock

Contribución activa en el desarrollo del sistema de gestión de recursos y seguridad en talleres y obras.

* **Repositorio:** [Safe Stock](https://github.com/Jalifimaia/Sistema-de-Gestion-de-recursos-y-Seguridad-en-talleres-y-obras)
* **Terminal Interactiva:** Implementación de reconocimiento de voz para gestión autónoma de préstamos.
* **Seguridad y Acceso:** Sistema de login mediante códigos QR, DNI y claves personalizadas.
* **Gestión de Herramientas:** Registro, devolución y escaneo QR con exportación masiva de reportes a PDF.
* **Calidad de Código:** Aplicación de tests unitarios y refactorización integral para mejorar la modularidad.
